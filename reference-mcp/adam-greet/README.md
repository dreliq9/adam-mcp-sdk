# adam-greet

Reference MCP for the Adam house style. Pulls weather + calendar + recent music to compose context-aware morning greetings. Mundane on purpose — it exists to exemplify every rule in `HOUSE_STYLE.md`.

## Install

```bash
cd ~/Projects/adam-mcp-sdk
uv sync
```

## Run as MCP

```bash
adam-greet-mcp
```

## Run as CLI

```bash
adam-greet Adam
```
